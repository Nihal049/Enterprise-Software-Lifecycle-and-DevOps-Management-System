# Enterprise Software Lifecycle and DevOps Management System 

A full-stack Application Lifecycle Management (ALM) platform designed to unify project tracking, code repositories, test cases, and CI/CD pipeline deployments into a single workspace.

## 🚀 Tech Stack
* **Frontend:** React, Tailwind CSS, Lucide Icons, Vite
* **Backend:** Java, Spring Boot
* **Database:** MySQL / PostgreSQL

## 📁 Project Structure
This is a monorepo containing both the frontend UI and the backend API.
* `/neuroforge-react` - The React frontend application.
* `/neuroforge_backend` - The Spring Boot backend service.
